About Gate Sync

browser puzzle · Practical AI Lab open game lab

Gate Sync is a free, no-account browser puzzle: guide a light along rails, match gate colors with one thumb, and clear short levels. It is published as a static front-end page for anyone to open without an app store install.

What this is: an original timing / rail color puzzle for the open web.
What this is not: an apartment access-control app, a smart-home product, a wallet or token-gating SDK, or a remake of any commercial endless-runner brand.

Practical AI Lab ships small zero-spend experiments. Gate Sync is game lab entry one: portrait-first, Web Audio blips only, and plain HTML/CSS/JS so it can live on GitHub Pages.

Name note: other industries use similar English words for door systems or analysis tools. This page is only the browser puzzle described here. No affiliation with those products.
